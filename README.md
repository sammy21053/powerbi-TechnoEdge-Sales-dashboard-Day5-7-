📊 Sales Performance Dashboard | Power BI

📌 Project Overview

This project analyzes multi-year sales data to uncover trends, regional performance, product contribution, and customer segment behavior. The goal is to help business stakeholders understand what’s driving revenue and profit — and where to focus next.

🎯 Problem Statement

Sales teams often track totals but miss:

Which regions truly outperform

Which categories generate profit vs volume

How customer segments behave over time

This dashboard solves that by centralizing key KPIs and enabling interactive exploration.

📈 Key KPIs

Total Sales

Total Profit

Profit Margin (%)

Total Quantity Sold

Regional Coverage (States)

📊 Dashboard Features

Region-wise sales distribution

Category & sub-category drilldowns

Segment-based performance comparison

Time-based analysis (Year / Quarter / Month)

Profit visualization using geographic mapping

Power BI
